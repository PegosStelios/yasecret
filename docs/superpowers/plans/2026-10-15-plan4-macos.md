# yasecret Plan 4 — macOS SwiftUI App

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a native macOS app (SwiftUI, macOS 14+) that lets users manage secrets via a 3-column GUI, unlocks with Touch ID or master password, and stores credentials in the system Keychain.

**Architecture:** A separate `crates/ffi/` Rust crate exposes `YasecretSession` via UniFFI 0.28 proc macros, building as a `cdylib`. An Xcode project (generated by `xcodegen` from `macos/project.yml`) links the Rust dylib and the generated Swift bindings. All UI is SwiftUI `@Observable` view models calling into the FFI layer. The Keychain stores the master password under a fixed service ID after first unlock; Touch ID gates retrieval on subsequent opens.

**Tech Stack:** UniFFI 0.28, xcodegen 2.x, SwiftUI macOS 14+, Security.framework (Keychain), LocalAuthentication.framework (Touch ID), UserNotifications.framework (TOFU alert)

**Spec:** docs/superpowers/specs/2026-10-15-yasecret-design.md

## Global Constraints

- Deployment target: macOS 14.0 (Sonoma) — enables `@Observable` macro
- UniFFI = "0.28" — exact; bindgen must be the workspace crate in `tools/uniffi-bindgen/`
- Secret values never stored in Swift `String` longer than needed — use `Zeroizing`-backed Rust returns, wipe local Swift vars after use
- `get_secret` / `get_plaintext` never logged or printed
- DB file permissions: 0600 (set by `Db::open` on Unix)
- Keychain service ID: `"com.yasecret.masterpassword"`
- MCP TOFU polling interval: 5 seconds (timer in AppState)
- `xcodebuild` build target: scheme `"Yasecret"`, destination `"platform=macOS,arch=arm64"`
- All Swift unit tests run without a simulator: `xcodebuild test -scheme YasecretTests -destination 'platform=macOS,arch=arm64'`

## Review Focus

1. **Wrong master password** — `YasecretSession.init` must throw `FfiError.WrongPassword`, never crash or silently succeed with garbage data; test in Task 1.
2. **Keychain entry absent on first launch** — `UnlockViewModel` must fall through to password prompt gracefully, not crash; test in Task 3.
3. **Touch ID not enrolled / policy eval fails** — app must fall back to password prompt, not freeze; test in Task 3.
4. **MCP TOFU row already exists** — second `mcp_run` must not insert a second row; polling timer must not show duplicate notifications; test in Task 7.
5. **Secret list with no project_key row** — `list_secrets` returns decryptable metadata only (keys + IDs); `get_plaintext` on missing key must throw `FfiError.NotFound`, not crash; test in Task 2 Rust tests.

```rust
uniffi::setup_scaffolding!();

use std::{path::Path, sync::Arc};
use yasecret_core::{db::Db, env_file, models::now};
use zeroize::Zeroizing;

// ── Error type ─────────────────────────────────────────────────────────────

#[derive(Debug, thiserror::Error, uniffi::Error)]
pub enum FfiError {
    #[error("Wrong password")]
    WrongPassword,
    #[error("Not found: {msg}")]
    NotFound { msg: String },
    #[error("Permission denied")]
    PermissionDenied,
    #[error("Crypto error")]
    Crypto,
    #[error("IO: {msg}")]
    Io { msg: String },
    #[error("Database: {msg}")]
    Db { msg: String },
    #[error("Parse: {msg}")]
    Parse { msg: String },
}

impl From<yasecret_core::error::YasecretError> for FfiError {
    fn from(e: yasecret_core::error::YasecretError) -> Self {
        use yasecret_core::error::YasecretError as E;
        match e {
            E::WrongPassword       => FfiError::WrongPassword,
            E::PermissionDenied    => FfiError::PermissionDenied,
            E::Crypto              => FfiError::Crypto,
            E::NotFound(m)         => FfiError::NotFound { msg: m },
            E::Db(e)               => FfiError::Db { msg: e.to_string() },
            E::Io(e)               => FfiError::Io { msg: e.to_string() },
            E::EnvParse(m)         => FfiError::Parse { msg: m },
            E::Serde(e)            => FfiError::Db { msg: e.to_string() },
        }
    }
}

// ── Record types (no sensitive data) ───────────────────────────────────────

#[derive(Clone, uniffi::Record)]
pub struct FfiProject {
    pub id: String,
    pub name: String,
    pub description: Option<String>,
}

#[derive(Clone, uniffi::Record)]
pub struct FfiEnvironment {
    pub id: String,
    pub project_id: String,
    pub name: String,
}

#[derive(Clone, uniffi::Record)]
pub struct FfiSecret {
    pub id: String,
    pub env_id: String,
    pub key: String,
    pub expires_at: Option<i64>,
}

// ── Session object ──────────────────────────────────────────────────────────

#[derive(uniffi::Object)]
pub struct YasecretSession {
    db_path: String,
    password: String,
    db_key: Zeroizing<[u8; 32]>,
}

#[uniffi::export]
impl YasecretSession {
    #[uniffi::constructor]
    pub fn new(db_path: String, password: String) -> Result<Arc<Self>, FfiError> {
        let path = Path::new(&db_path);

        // Load or create salt alongside db.sqlite as db.salt
        let salt_path = path.with_extension("salt");
        let salt: [u8; 16] = if salt_path.exists() {
            std::fs::read(&salt_path)
                .map_err(|e| FfiError::Io { msg: e.to_string() })?
                .try_into()
                .map_err(|_| FfiError::Io { msg: "salt file corrupt (expected 16 bytes)".into() })?
        } else {
            let s = yasecret_core::crypto::generate_salt();
            std::fs::write(&salt_path, s).map_err(|e| FfiError::Io { msg: e.to_string() })?;
            s
        };

        let db_key = yasecret_core::crypto::derive_db_key(&password, &salt);

        // Verify password; Db::open returns WrongPassword on bad key
        Db::open(path, &password)?;

        Ok(Arc::new(Self { db_path, password, db_key }))
    }

    // ── Projects ─────────────────────────────────────────────────────────

    pub fn list_projects(&self) -> Result<Vec<FfiProject>, FfiError> {
        let db = self.open()?;
        Ok(yasecret_core::project::list(&db)?
            .into_iter()
            .map(|p| FfiProject { id: p.id, name: p.name, description: p.description })
            .collect())
    }

    pub fn create_project(&self, name: String, description: Option<String>) -> Result<FfiProject, FfiError> {
        let db = self.open()?;
        let id = yasecret_core::identity::load_or_create(&db, "local")
            .map_err(FfiError::from)?.id;
        let p = yasecret_core::project::create(&db, &name, description.as_deref(), &id)?;
        // Also create a project key so secrets can be stored immediately
        yasecret_core::project_key::create(&db, &p.id, &self.db_key)?;
        Ok(FfiProject { id: p.id, name: p.name, description: p.description })
    }

    pub fn delete_project(&self, project_id: String) -> Result<(), FfiError> {
        let db = self.open()?;
        Ok(yasecret_core::project::delete(&db, &project_id)?)
    }

    // ── Environments ─────────────────────────────────────────────────────

    pub fn list_environments(&self, project_id: String) -> Result<Vec<FfiEnvironment>, FfiError> {
        let db = self.open()?;
        Ok(yasecret_core::environment::list(&db, &project_id)?
            .into_iter()
            .map(|e| FfiEnvironment { id: e.id, project_id: e.project_id, name: e.name })
            .collect())
    }

    pub fn create_environment(&self, project_id: String, name: String) -> Result<FfiEnvironment, FfiError> {
        let db = self.open()?;
        let e = yasecret_core::environment::create(&db, &project_id, &name)?;
        Ok(FfiEnvironment { id: e.id, project_id: e.project_id, name: e.name })
    }

    pub fn delete_environment(&self, env_id: String) -> Result<(), FfiError> {
        let db = self.open()?;
        Ok(yasecret_core::environment::delete(&db, &env_id)?)
    }

    // ── Secrets ───────────────────────────────────────────────────────────

    pub fn list_secrets(&self, env_id: String) -> Result<Vec<FfiSecret>, FfiError> {
        let db = self.open()?;
        Ok(yasecret_core::secret::list(&db, &env_id)?
            .into_iter()
            .map(|s| FfiSecret { id: s.id, env_id: s.env_id, key: s.key, expires_at: s.expires_at })
            .collect())
    }

    pub fn create_secret(
        &self,
        project_id: String,
        env_id: String,
        key: String,
        value: String,
        expires_at: Option<i64>,
    ) -> Result<FfiSecret, FfiError> {
        let db = self.open()?;
        let proj_key = yasecret_core::project_key::load(&db, &project_id, &self.db_key)?;
        let id = yasecret_core::identity::load_or_create(&db, "local")?.id;
        let s = yasecret_core::secret::create(
            &db, &env_id, &key, value.as_bytes(), &proj_key, &id, expires_at,
        )?;
        Ok(FfiSecret { id: s.id, env_id: s.env_id, key: s.key, expires_at: s.expires_at })
    }

    pub fn update_secret(
        &self,
        project_id: String,
        secret_id: String,
        new_value: String,
    ) -> Result<(), FfiError> {
        let db = self.open()?;
        let proj_key = yasecret_core::project_key::load(&db, &project_id, &self.db_key)?;
        let id = yasecret_core::identity::load_or_create(&db, "local")?.id;
        yasecret_core::secret::update(&db, &secret_id, new_value.as_bytes(), &proj_key, &id, None)?;
        Ok(())
    }

    pub fn delete_secret(&self, secret_id: String) -> Result<(), FfiError> {
        let db = self.open()?;
        let id = yasecret_core::identity::load_or_create(&db, "local")?.id;
        Ok(yasecret_core::secret::delete(&db, &secret_id, &id)?)
    }

    pub fn get_secret_plaintext(
        &self,
        project_id: String,
        secret_id: String,
    ) -> Result<String, FfiError> {
        let db = self.open()?;
        let proj_key = yasecret_core::project_key::load(&db, &project_id, &self.db_key)?;
        let bytes = yasecret_core::secret::get_plaintext(&db, &secret_id, &proj_key)?;
        String::from_utf8(bytes.to_vec())
            .map_err(|e| FfiError::Parse { msg: e.to_string() })
    }

    // ── Import / Export ───────────────────────────────────────────────────

    pub fn import_env(
        &self,
        project_id: String,
        env_id: String,
        content: String,
    ) -> Result<u32, FfiError> {
        let db = self.open()?;
        let proj_key = yasecret_core::project_key::load(&db, &project_id, &self.db_key)?;
        let id = yasecret_core::identity::load_or_create(&db, "local")?.id;
        let pairs = env_file::parse(&content)?;
        let mut count = 0u32;
        for (key, value) in &pairs {
            yasecret_core::secret::create(
                &db, &env_id, key, value.as_bytes(), &proj_key, &id, None,
            )?;
            count += 1;
        }
        Ok(count)
    }

    pub fn export_env(
        &self,
        project_id: String,
        env_id: String,
    ) -> Result<String, FfiError> {
        let db = self.open()?;
        let proj_key = yasecret_core::project_key::load(&db, &project_id, &self.db_key)?;
        let secrets = yasecret_core::secret::list(&db, &env_id)?;
        let mut pairs: Vec<(String, String)> = vec![];
        for s in &secrets {
            let val = yasecret_core::secret::get_plaintext(&db, &s.id, &proj_key)?;
            pairs.push((s.key.clone(), String::from_utf8_lossy(&val).into_owned()));
        }
        Ok(env_file::serialize(&pairs))
    }
}

// ── Free functions ─────────────────────────────────────────────────────────

#[uniffi::export]
pub fn default_db_path() -> String {
    let mut base = dirs::data_local_dir().unwrap_or_else(|| std::path::PathBuf::from("."));
    base.push("yasecret");
    std::fs::create_dir_all(&base).ok();
    base.push("db.sqlite");
    base.to_string_lossy().into_owned()
}

impl YasecretSession {
    fn open(&self) -> Result<Db, FfiError> {
        Ok(Db::open(Path::new(&self.db_path), &self.password)?)
    }
}
```

```swift
final class FfiSmokeTests: XCTestCase {
    func testDefaultDbPathIsNonEmpty() throws {
        // Calls the Rust free function via UniFFI
        let path = defaultDbPath()
        XCTAssertFalse(path.isEmpty)
        XCTAssertTrue(path.hasSuffix("db.sqlite"), "expected db.sqlite, got: \(path)")

    func testSessionWrongPasswordThrows() throws {
        let dir = FileManager.default.temporaryDirectory
            .appendingPathComponent(UUID().uuidString)
        try FileManager.default.createDirectory(at: dir, withIntermediateDirectories: true)
        defer { try? FileManager.default.removeItem(at: dir) }

        let dbPath = dir.appendingPathComponent("db.sqlite").path

        // Create DB with correct password first (salt is auto-created)
        let _ = try YasecretSession(dbPath: dbPath, password: "correct")

        XCTAssertThrowsError(
            try YasecretSession(dbPath: dbPath, password: "wrong")
        ) { error in
            guard let ffiErr = error as? FfiError else {
                XCTFail("Expected FfiError, got \(error)"); return
            }
            XCTAssertEqual(ffiErr, FfiError.wrongPassword)
        }
    }
}
```

```swift
import Foundation
import Security

final class KeychainService {
    private let service = "com.yasecret.masterpassword"
    private let account: String

    init(account: String = "default") {
        self.account = account
    }

    func save(password: String) {
        delete() // remove any existing entry first
        guard let data = password.data(using: .utf8) else { return }
        let query: [CFString: Any] = [
            kSecClass:       kSecClassGenericPassword,
            kSecAttrService: service,
            kSecAttrAccount: account,
            kSecValueData:   data,
            kSecAttrAccessible: kSecAttrAccessibleWhenUnlockedThisDeviceOnly,
        ]
        SecItemAdd(query as CFDictionary, nil)
    }

    func load() -> String? {
        let query: [CFString: Any] = [
            kSecClass:            kSecClassGenericPassword,
            kSecAttrService:      service,
            kSecAttrAccount:      account,
            kSecReturnData:       true,
            kSecMatchLimit:       kSecMatchLimitOne,
        ]
        var result: AnyObject?
        let status = SecItemCopyMatching(query as CFDictionary, &result)
        guard status == errSecSuccess,
              let data = result as? Data,
              let pw = String(data: data, encoding: .utf8) else { return nil }
        return pw
    }

    func delete() {
        let query: [CFString: Any] = [
            kSecClass:       kSecClassGenericPassword,
            kSecAttrService: service,
            kSecAttrAccount: account,
        ]
        SecItemDelete(query as CFDictionary)
    }
}
```

```swift
import Foundation

@Observable
final class UnlockViewModel {
    var password: String = ""
    var errorMessage: String?
    var isUnlocking: Bool = false

    private let appState: AppState
    private let dbPath: String
    private let keychain = KeychainService()
    private let biometrics = BiometricService()

    init(appState: AppState, dbPath: String) {
        self.appState = appState
        self.dbPath = dbPath
    }

    /// Try biometrics first; fall back to stored password, then prompt.
    func tryBiometricUnlock() async {
        guard let stored = keychain.load() else { return }
        let ok = await biometrics.authenticate()
        guard ok else { return }
        await unlock(with: stored)
    }

    /// Unlock with current `password` property (from text field).
    func unlock() async {
        await unlock(with: password)
    }

    private func unlock(with pw: String) async {
        isUnlocking = true
        errorMessage = nil
        defer { isUnlocking = false }
        do {
            let session = try YasecretSession(dbPath: dbPath, password: pw)
            keychain.save(password: pw)
            appState.session = session
            appState.isLocked = false
            appState.startMcpPolling()
        } catch {
            errorMessage = "Wrong password — try again"
            appState.session = nil
            appState.isLocked = true
        }
    }
}
```

Replace the stub `pollMcpSession` in `macos/Sources/App/AppState.swift`:

```swift
import Foundation

@Observable
final class AppState {
    var session: YasecretSession?
    var isLocked: Bool = true
    var mcpSessionCount: Int = 0
    private var lastKnownMcpCount: Int = 0
    private var mcpPollTimer: Timer?

    func startMcpPolling() {
        NotificationService.shared.requestPermission()
        // snapshot current count so we don't fire on existing rows
        lastKnownMcpCount = (try? session?.mcpSessionCount().map(Int.init)) ?? 0
        mcpPollTimer = Timer.scheduledTimer(withTimeInterval: 5.0, repeats: true) { [weak self] _ in
            self?.pollMcpSession()
        }
    }

    func stopMcpPolling() {
        mcpPollTimer?.invalidate()
        mcpPollTimer = nil
    }

    private func pollMcpSession() {
        guard let session else { return }
        guard let count = try? session.mcpSessionCount().map(Int.init) else { return }
        if count > lastKnownMcpCount {
            lastKnownMcpCount = count
            mcpSessionCount = count
            NotificationService.shared.notifyMcpAccess()
        }
    }
}
```
