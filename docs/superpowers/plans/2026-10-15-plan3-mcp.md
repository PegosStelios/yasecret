# yasecret Plan 3 — MCP Server

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `yasecret mcp` stdio MCP server exposing 5 tools so Claude Code can list, run, and import secrets.

**Architecture:** Single `crates/cli/src/mcp_server.rs` module holds the `YasecretServer` struct with all 5 tools declared via rmcp's `#[tool_router]` + `#[tool_handler]` macros. The `yasecret mcp` CLI command starts the server over stdio. The struct holds `db_path + password + allow_plaintext`; each tool re-opens the DB per call (rusqlite `Connection` is `!Send`). TOFU: auto-grant on first run in CLI context (no GUI yet); a token row is inserted into `mcp_session` on first start. `get_secret` is guarded by `YASECRET_MCP_ALLOW_PLAINTEXT=1` env var (GUI opt-in is Plan 4).

**Tech Stack:** rmcp 3.5.1 (`server`, `macros`, `transport-io`, `schemars` features), schemars 0.8, existing yasecret-core

**Spec:** docs/superpowers/specs/2026-10-15-yasecret-design.md

## Global Constraints

- rmcp = "3.5.1" — exact version, macros + transport-io features required
- schemars = "0.8" — required by rmcp schemars feature
- Secret values NEVER appear in log output, error strings, or tool descriptions
- `get_secret` gated behind `YASECRET_MCP_ALLOW_PLAINTEXT=1` env var in CLI context
- `run_with_secrets` output MUST have all decrypted values masked before returning to Claude
- No `process::exit` inside tool handlers — return error strings instead
- TOFU token: insert into `mcp_session` on first run if table empty; do not error if already populated

## Review Focus

1. **`get_secret` without opt-in** — must return an error string, never the plaintext value
2. **`run_with_secrets` with a secret value that appears in its own command args** — masking must cover both stdout and stderr; command args must not be returned to Claude
3. **`import_env` with malformed .env line** — must return a descriptive error string, not panic
4. **TOFU on empty DB** — `mcp_session` must have exactly one row after first start, not zero
5. **`list_secret_keys` for a nonexistent project/env** — must return a helpful error string, not panic

```rust
use clap::Args;
use rmcp::ServiceExt;
use yasecret_core::YasecretError;

#[derive(Args)]
pub struct McpArgs {
    #[arg(long, hide = true)]
    pub db: Option<String>,
    #[arg(long, hide = true)]
    pub password: Option<String>,
}

pub async fn run(args: McpArgs) -> yasecret_core::Result<()> {
    let path = crate::unlock::db_path(args.db.as_deref());
    let session = crate::unlock::unlock(&path, args.password.as_deref())?;
    let allow_plaintext = std::env::var("YASECRET_MCP_ALLOW_PLAINTEXT").as_deref() == Ok("1");

    // TOFU: insert a session token on first run
    let token_count: i64 = session.db.conn()
        .query_row("SELECT count(*) FROM mcp_session", [], |r| r.get(0))
        .unwrap_or(0);
    if token_count == 0 {
        let token = uuid::Uuid::new_v4().to_string();
        session.db.conn().execute(
            "INSERT INTO mcp_session (token, granted_at) VALUES (?1, ?2)",
            rusqlite::params![&token, yasecret_core::models::now()],
        ).map_err(YasecretError::Db)?;
        eprintln!("yasecret: MCP access auto-granted (CLI mode). Token: {token}");
    }

    let server = crate::mcp_server::YasecretServer::new(&path, session.db.conn()
        .query_row("SELECT 1", [], |_| Ok(())).map(|_| args.password.clone().unwrap_or_default())
        .unwrap_or_default(), allow_plaintext);

    // Actually we need the raw password string, not the derived key.
    // Re-create from args:
    let password = args.password.unwrap_or_else(|| {
        rpassword::prompt_password("Master password: ").unwrap_or_default()
    });
    let server = crate::mcp_server::YasecretServer::new(&path, password, allow_plaintext);

    let running = server
        .serve(rmcp::transport::io::stdio())
        .await
        .map_err(|e| YasecretError::Io(std::io::Error::other(e.to_string())))?;
    running
        .waiting()
        .await
        .map_err(|e| YasecretError::Io(std::io::Error::other(e.to_string())))?;
    Ok(())
}
```

```rust
use clap::Args;
use rmcp::ServiceExt;
use yasecret_core::YasecretError;
use rusqlite::params;

#[derive(Args)]
pub struct McpArgs {
    #[arg(long, hide = true)]
    pub db: Option<String>,
    #[arg(long, hide = true)]
    pub password: Option<String>,
}

pub async fn run(args: McpArgs) -> yasecret_core::Result<()> {
    let path = crate::unlock::db_path(args.db.as_deref());

    // Read password once; use it for both unlock and the server.
    let password = match &args.password {
        Some(p) => p.clone(),
        None => rpassword::prompt_password("Master password: ")
            .map_err(YasecretError::Io)?,
    };

    // Verify DB is accessible and do TOFU.
    {
        let db = yasecret_core::db::Db::open(&path, &password)?;
        let token_count: i64 = db.conn()
            .query_row("SELECT count(*) FROM mcp_session", [], |r| r.get(0))
            .unwrap_or(0);
        if token_count == 0 {
            let token = uuid::Uuid::new_v4().to_string();
            db.conn().execute(
                "INSERT INTO mcp_session (token, granted_at) VALUES (?1, ?2)",
                params![&token, yasecret_core::models::now()],
            ).map_err(YasecretError::Db)?;
            eprintln!("yasecret: MCP access granted (CLI mode). Token stored.");
        }
    }

    let allow_plaintext = std::env::var("YASECRET_MCP_ALLOW_PLAINTEXT").as_deref() == Ok("1");
    let server = crate::mcp_server::YasecretServer::new(&path, password, allow_plaintext);

    let running = server
        .serve(rmcp::transport::io::stdio())
        .await
        .map_err(|e| YasecretError::Io(std::io::Error::other(e.to_string())))?;
    running
        .waiting()
        .await
        .map_err(|e| YasecretError::Io(std::io::Error::other(e.to_string())))?;
    Ok(())
}
```

```rust
use yasecret_core::{environment, project};

impl YasecretServer {
    pub fn list_projects_impl(&self) -> String {
        let db = match self.open_db() { Ok(d) => d, Err(e) => return format!("error: {e}") };
        let projects = match project::list(&db) { Ok(p) => p, Err(e) => return format!("error: {e}") };
        let mut out = vec![];
        for proj in &projects {
            let envs = environment::list(&db, &proj.id).unwrap_or_default();
            let env_names: Vec<&str> = envs.iter().map(|e| e.name.as_str()).collect();
            out.push(format!(r#"{{"project":"{}","envs":{:?}}}"#, proj.name, env_names));
        }
        format!("[{}]", out.join(","))
    }

    pub fn list_secret_keys_impl(&self, project_name: &str, env_name: &str) -> String {
        let db = match self.open_db() { Ok(d) => d, Err(e) => return format!("error: {e}") };
        let projects = match project::list(&db) { Ok(p) => p, Err(e) => return format!("error: {e}") };
        let proj = match projects.iter().find(|p| p.name == project_name) {
            Some(p) => p,
            None => return format!("error: project '{}' not found", project_name),
        };
        let envs = match environment::list(&db, &proj.id) { Ok(e) => e, Err(e) => return format!("error: {e}") };
        let env = match envs.iter().find(|e| e.name == env_name) {
            Some(e) => e,
            None => return format!("error: environment '{}' not found in project '{}'", env_name, project_name),
        };
        let secrets = match yasecret_core::secret::list(&db, &env.id) { Ok(s) => s, Err(e) => return format!("error: {e}") };
        let keys: Vec<&str> = secrets.iter().map(|s| s.key.as_str()).collect();
        format!("{:?}", keys)
    }
}
```

```rust
use std::process::{Command as StdCommand, Stdio};
use zeroize::Zeroizing;
use yasecret_core::{crypto, project_key};

impl YasecretServer {
    pub fn run_with_secrets_impl(
        &self,
        project_name: &str,
        env_name: &str,
        keys: &[String],
        cmd: &[String],
    ) -> String {
        if cmd.is_empty() {
            return "error: cmd must have at least one element".to_string();
        }
        let db = match self.open_db() { Ok(d) => d, Err(e) => return format!("error: {e}") };

        let projects = match yasecret_core::project::list(&db) { Ok(p) => p, Err(e) => return format!("error: {e}") };
        let proj = match projects.iter().find(|p| p.name == project_name) {
            Some(p) => p, None => return format!("error: project '{}' not found", project_name),
        };
        let envs = match yasecret_core::environment::list(&db, &proj.id) { Ok(e) => e, Err(e) => return format!("error: {e}") };
        let env = match envs.iter().find(|e| e.name == env_name) {
            Some(e) => e, None => return format!("error: environment '{}' not found", env_name),
        };

        let db_key = self.open_db_key_zeroize();  // see note below
        let proj_key = match project_key::load(&db, &proj.id, &db_key) {
            Ok(k) => k, Err(e) => return format!("error: {e}"),
        };
        let all_secrets = match yasecret_core::secret::list(&db, &env.id) {
            Ok(s) => s, Err(e) => return format!("error: {e}"),
        };

        let mut env_vars: Vec<(String, Zeroizing<Vec<u8>>)> = vec![];
        for s in &all_secrets {
            if keys.is_empty() || keys.contains(&s.key) {
                let nonce: [u8; 12] = match s.nonce.clone().try_into() {
                    Ok(n) => n, Err(_) => return "error: corrupt nonce".to_string(),
                };
                match crypto::decrypt(&s.encrypted_value, &nonce, &proj_key) {
                    Ok(v) => env_vars.push((s.key.clone(), v)),
                    Err(e) => return format!("error decrypting '{}': {e}", s.key),
                }
            }
        }

        let secret_values: Vec<String> = env_vars
            .iter()
            .map(|(_, v)| String::from_utf8_lossy(v).into_owned())
            .collect();

        let mut process = StdCommand::new(&cmd[0]);
        process.args(&cmd[1..]);
        for (key, val) in &env_vars {
            process.env(key, String::from_utf8_lossy(val).as_ref());
        }
        process.stdout(Stdio::piped()).stderr(Stdio::piped());

        let output = match process.output() {
            Ok(o) => o, Err(e) => return format!("error running command: {e}"),
        };

        let stdout = mask(&String::from_utf8_lossy(&output.stdout), &secret_values);
        let stderr = mask(&String::from_utf8_lossy(&output.stderr), &secret_values);
        let status = output.status.code().unwrap_or(-1);

        format!("exit_code: {status}\nstdout:\n{stdout}\nstderr:\n{stderr}")
    }
}

fn mask(output: &str, secrets: &[String]) -> String {
    let mut result = output.to_string();
    for s in secrets {
        if !s.is_empty() {
            result = result.replace(s.as_str(), "[REDACTED]");
        }
    }
    result
}
```

Note on `open_db_key_zeroize`: the server needs the raw `db_key` (32-byte Argon2 output) to load the project key. But we only store the password string — not the derived key. Re-derive it each call:

```rust
impl YasecretServer {
    fn open_db_key(&self) -> Result<zeroize::Zeroizing<[u8; 32]>, String> {
        // Read salt from db.salt file alongside db.sqlite
        let salt_path = self.db_path.with_extension("salt");
        let salt_bytes = std::fs::read(&salt_path)
            .map_err(|e| format!("cannot read salt: {e}"))?;
        let salt: [u8; 16] = salt_bytes.try_into()
            .map_err(|_| "salt must be 16 bytes".to_string())?;
        Ok(yasecret_core::crypto::derive_db_key(&self.password, &salt))
    }
}
```

```rust
impl YasecretServer {
    pub fn import_env_impl(&self, project_name: &str, env_name: &str, content: &str) -> String {
        let db = match self.open_db() { Ok(d) => d, Err(e) => return format!("error: {e}") };
        let db_key = match self.open_db_key() { Ok(k) => k, Err(e) => return format!("error: {e}") };

        let pairs = match yasecret_core::env_file::parse(content) {
            Ok(p) => p, Err(e) => return format!("error parsing .env: {e}"),
        };

        let projects = match yasecret_core::project::list(&db) { Ok(p) => p, Err(e) => return format!("error: {e}") };
        let proj = match projects.iter().find(|p| p.name == project_name) {
            Some(p) => p, None => return format!("error: project '{}' not found", project_name),
        };
        let envs = match yasecret_core::environment::list(&db, &proj.id) { Ok(e) => e, Err(e) => return format!("error: {e}") };
        let env = match envs.iter().find(|e| e.name == env_name) {
            Some(e) => e, None => return format!("error: environment '{}' not found", env_name),
        };
        let proj_key = match yasecret_core::project_key::load(&db, &proj.id, &db_key) {
            Ok(k) => k, Err(e) => return format!("error: {e}"),
        };
        let identity = match yasecret_core::identity::load(&db) {
            Ok(id) => id, Err(e) => return format!("error loading identity: {e}"),
        };

        let mut count = 0;
        for (key, value) in &pairs {
            match yasecret_core::secret::create(
                &db, &env.id, key, value.as_bytes(), &proj_key, &identity.id, None,
            ) {
                Ok(_) => count += 1,
                Err(e) => return format!("error importing key '{key}': {e}"),
            }
        }
        format!("imported {count} secret(s)")
    }
}
```
