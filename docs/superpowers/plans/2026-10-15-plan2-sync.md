# yasecret Plan 2: sync crate — iroh P2P layer

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `crates/sync` — the iroh P2P layer that lets two peers share an encrypted project via a `DocTicket`, syncing secrets/roles/keys through an iroh-docs CRDT document.

**Architecture:** `crates/sync` is a pure Rust async crate wrapping `iroh` and `iroh-docs`. It exposes a `SyncNode` (iroh node lifecycle), doc management (create/join/ticket), peer key encryption (wraps `core::crypto`), and a background applier that translates incoming doc entries into local DB writes. The CLI gains `share`, `join`, and `peers` subcommands; `main()` becomes `async` via `#[tokio::main]`.

**Tech Stack:** Rust, iroh ~0.28, iroh-docs ~0.28, tokio 1 (full), serde_json, anyhow, yasecret-core

**Spec:** `docs/superpowers/specs/2026-10-15-yasecret-design.md`

> **iroh API note:** iroh evolves rapidly. Before starting Task 4, run `cargo add iroh iroh-docs` without pinning and check `cargo doc --open` for the actual method names. The API sketched in this plan matches iroh ~0.28/iroh-docs ~0.28. Adjust method names if needed; the behavior contract is what matters.

## Global Constraints

- No Claude/AI attribution in any git commit (no `Co-Authored-By` lines).
- Workspace resolver = "2" (already set).
- `core` crate is synchronous (rusqlite `Connection` is `!Send`); sync crate bridges to async via `tokio::task::spawn_blocking` and per-call `Db::open`.
- Secret bytes always in `Zeroizing<…>`; never in `String` or plain `Vec<u8>` in plaintext form.
- DB file at 0600; existing `Db::open` handles this.
- iroh node secret key stored in `{data_dir}/sync.key` (32 raw bytes), separate from the DB master password.
- All role entries verified with `core::role::verify_signature` before writing to DB — forged roles silently dropped.

## Review Focus

1. **Malformed DocTicket string** — `join_project_doc` must return `Err(SyncError::InvalidTicket)`, not panic; add test `join_with_garbage_ticket_errors` to Task 5.
2. **Wrong X25519 key** — `load_my_peer_key` called with an identity whose private key doesn't match the encrypted blob must return `Err(SyncError::Core(YasecretError::Crypto))`, not panic; add test `load_my_peer_key_wrong_identity_errors` to Task 3.
3. **Invalid-signature role in doc** — applier must drop the entry and leave DB unchanged; add test `apply_role_bad_signature_ignored` to Task 6.
4. **Corrupted sync.key file** — `SyncNode::start` must return `Err` when sync.key is not 32 bytes; add test `start_with_corrupt_key_file_errors` to Task 4.
5. **CRDT concurrent write to same secret** — iroh-docs LWW picks one winner, but `secret_version` must preserve the losing version too (manual verification item; no automated test is written, flagged in the ledger).

### Task 3: Peer key store/load

**Files:**
- Modify: `crates/sync/src/peer_key.rs`
- Test: `crates/sync/tests/peer_key_test.rs`

**Interfaces:**
- Consumes:
  - `yasecret_core::crypto::{encrypt_for_peer, decrypt_from_peer}` — `encrypt_for_peer(plaintext: &[u8], peer_pub_bytes: &[u8; 32]) -> core::Result<Vec<u8>>`, `decrypt_from_peer(data: &[u8], our_secret: &x25519_dalek::StaticSecret) -> core::Result<Zeroizing<Vec<u8>>>`
  - `yasecret_core::db::Db`
  - `yasecret_core::models::Identity` — `identity.x25519_secret() -> StaticSecret`, `identity.x25519_public() -> PublicKey` (`.as_bytes() -> &[u8;32]`)
- Produces:
  - `peer_key::store_peer_key(db: &Db, project_id: &str, peer_id: &str, peer_pub_bytes: &[u8; 32], project_key: &[u8; 32]) -> Result<()>`
  - `peer_key::load_my_peer_key(db: &Db, project_id: &str, our_identity: &Identity) -> Result<Zeroizing<[u8; 32]>>`

`store_peer_key` uses `core::crypto::encrypt_for_peer` to encrypt `project_key` for the peer's X25519 pub key, stores the blob in `peer_project_key(project_id, peer_id, encrypted_key)`.

`load_my_peer_key` reads the row where `peer_id = hex(our_identity.x25519_public())`, calls `decrypt_from_peer`, converts the 32-byte result to `[u8; 32]`.

**Peer ID convention:** the peer_id column in `peer_project_key` is the lowercase hex-encoded X25519 public key bytes — 64 hex chars. Same for all other peer references in the sync crate.

- [ ] **Step 3: Implement `crates/sync/src/peer_key.rs`**

```rust
use yasecret_core::{crypto, db::Db, models::Identity};
use zeroize::Zeroizing;

use crate::{Result, SyncError};

/// Encrypt `project_key` for `peer_pub_bytes` (X25519) and store in peer_project_key table.
/// `peer_id` is the lowercase hex of the peer's X25519 public key (64 chars).
pub fn store_peer_key(
    db: &Db,
    project_id: &str,
    peer_id: &str,
    peer_pub_bytes: &[u8; 32],
    project_key: &[u8; 32],
) -> Result<()> {
    let blob = crypto::encrypt_for_peer(project_key, peer_pub_bytes)?;
    db.conn().execute(
        "INSERT OR REPLACE INTO peer_project_key (project_id, peer_id, encrypted_key) VALUES (?1,?2,?3)",
        rusqlite::params![project_id, peer_id, &blob],
    )?;
    Ok(())
}

/// Load and decrypt the project key that was encrypted for our X25519 identity.
/// Looks up the row by `hex(our_identity.x25519_public())`.
pub fn load_my_peer_key(
    db: &Db,
    project_id: &str,
    our_identity: &Identity,
) -> Result<Zeroizing<[u8; 32]>> {
    let our_pub = our_identity.x25519_public();
    let peer_id = hex::encode(our_pub.as_bytes());
    let blob: Vec<u8> = db
        .conn()
        .query_row(
            "SELECT encrypted_key FROM peer_project_key WHERE project_id=?1 AND peer_id=?2",
            rusqlite::params![project_id, &peer_id],
            |r| r.get(0),
        )
        .map_err(|_| SyncError::NoPeerKey)?;

    let our_secret = our_identity.x25519_secret();
    let decrypted = crypto::decrypt_from_peer(&blob, &our_secret)?;
    let key_bytes: [u8; 32] = decrypted
        .as_slice()
        .try_into()
        .map_err(|_| SyncError::Core(yasecret_core::YasecretError::Crypto))?;
    Ok(Zeroizing::new(key_bytes))
}
```

```rust
use std::path::{Path, PathBuf};

use rand::rngs::OsRng;
use rand::RngCore;

use crate::{Result, SyncError};

pub struct SyncNode {
    node: iroh::node::Node<iroh::blobs::store::mem::Store>,
    // NOTE: The concrete Node generic type depends on iroh version.
    // If iroh::node::Node doesn't have this signature, use the type
    // returned by the builder's spawn() — e.g. iroh::node::MemNode or similar.
}

impl SyncNode {
    /// Start an iroh node.
    /// `data_dir`: directory for iroh's persistent state.
    /// `key_bytes`: ignored if `data_dir/sync.key` already exists (uses stored key).
    /// If `sync.key` exists but is not 32 bytes, returns Err.
    pub async fn start(data_dir: &Path, _key_bytes: &[u8; 32]) -> Result<Self> {
        let key_path = data_dir.join("sync.key");

        let secret_bytes: [u8; 32] = if key_path.exists() {
            let bytes = std::fs::read(&key_path)?;
            if bytes.len() != 32 {
                return Err(SyncError::Io(std::io::Error::new(
                    std::io::ErrorKind::InvalidData,
                    format!("sync.key must be 32 bytes, got {}", bytes.len()),
                )));
            }
            bytes.try_into().unwrap()
        } else {
            let mut b = [0u8; 32];
            OsRng.fill_bytes(&mut b);
            std::fs::create_dir_all(data_dir)?;
            std::fs::write(&key_path, &b)?;
            b
        };

        // iroh::SecretKey — check your iroh version for the exact constructor:
        // Option A (iroh ≥0.26): iroh::SecretKey::from_bytes(&secret_bytes)
        // Option B: iroh::key::SecretKey::generate() if from_bytes unavailable
        let secret_key = iroh::SecretKey::from_bytes(&secret_bytes);

        // iroh::node::Node::persistent builds a node with disk storage.
        // Adjust builder chain to match the installed iroh API.
        let node = iroh::node::Node::persistent(data_dir)
            .await
            .map_err(anyhow::Error::from)?
            .secret_key(secret_key)
            .spawn()
            .await
            .map_err(anyhow::Error::from)?;

        Ok(Self { node })
    }

    /// Returns the iroh NodeId as a lowercase hex string.
    pub fn node_id(&self) -> String {
        // iroh::NodeId implements Display as base32z; use fmt or .to_bytes()
        // If to_string() gives base32, use that; otherwise hex-encode to_bytes().
        let id = self.node.node_id();
        // Try: id.to_string() — use that if non-empty and stable.
        // Fallback: hex::encode(id.as_bytes()) if to_bytes() exists.
        id.to_string()
    }

    /// Returns a reference to the iroh client for doc/author operations.
    pub fn client(&self) -> iroh::client::MemClient {
        // Adjust: self.node.client() returns the client type.
        // The type name varies by iroh version (MemClient, RpcClient, etc.)
        self.node.client().clone()
    }

    pub async fn stop(self) {
        // Graceful shutdown; iroh::node::Node has shutdown() or drop handles it.
        // Check iroh docs: self.node.shutdown().await or just drop(self.node).
        drop(self.node);
    }
}
```

```rust
    db.conn().execute(
        "INSERT INTO sync_doc (project_id, doc_id, ticket) VALUES (?1,?2,?3)",

/// Join an existing iroh doc from a DocTicket string.
/// Stores (project_id, doc_id) in sync_doc. Returns doc_id string.
pub async fn join_project_doc(
    db: &Db,
    node: &SyncNode,
    ticket_str: &str,
    project_id: &str,
) -> Result<String> {
    let ticket: iroh_docs::DocTicket = ticket_str
        .parse()
        .map_err(|_| SyncError::InvalidTicket)?;

    let client = node.client();

        .docs()
        .import(ticket)
        .await
        .map_err(anyhow::Error::from)?;

    let doc_id = doc.id().to_string();

    db.conn().execute(
        "INSERT OR REPLACE INTO sync_doc (project_id, doc_id, ticket) VALUES (?1,?2,?3)",
        rusqlite::params![project_id, &doc_id, ticket_str],
    )?;

    Ok(doc_id)
}
```

`subscribe_and_apply` runs in a background tokio task. For each `LiveEvent::InsertRemote`:
1. Parse the entry key (UTF-8) to determine type.
2. Read the entry content bytes.
3. Dispatch to the correct apply function via `spawn_blocking`.

Applier dispatch table (key prefix → action):
- `project/meta` → upsert project in local DB
- `env/*/meta` → upsert environment
- `secret/*/*` → upsert secret (INSERT OR REPLACE on `(env_id, key)` unique index); archive old value as `secret_version` if updating
- `role/*/*` → verify signature; if valid, `role::grant` (or INSERT OR IGNORE if already exists)
- `peer_key/*` → skip if `peer_id` != `hex(our_identity.x25519_public())` — not for us; if ours, write to `peer_project_key`

```rust
    let key = doc_keys::role(&role.peer_id, role.env_id.as_deref());
    write_entry(node, doc_id, &key, bytes, author).await
}

/// Apply a SyncRole to the local DB.
/// Verifies the Ed25519 signature; silently drops the entry if invalid.
/// `owner_pub_key`: the owner's X25519 public key bytes (used for signature verification).
/// Note: role::verify_signature takes the Ed25519 verifying key; owner's signing key was
/// derived from the same 32 bytes as their X25519 secret in core's Identity::signing_key().
/// The owner_pub_key here comes from SyncProjectMeta.owner_pub_key (hex); we re-use the same
/// bytes as the Ed25519 verifying key (consistent with how identity.rs derives both keys).
pub fn apply_role_entry(db: &Db, sync_role: &SyncRole, owner_vk_bytes: &[u8; 32]) -> Result<()> {
    let level = match RoleLevel::from_str(&sync_role.level) {
        Some(l) => l,
        None => return Ok(()), // unknown level — drop silently
    };
    let role = Role {
        id: sync_role.id.clone(),
        project_id: sync_role.project_id.clone(),
        env_id: sync_role.env_id.clone(),
        peer_id: sync_role.peer_id.clone(),
        level,
        granted_at: sync_role.granted_at,
        signature: sync_role.signature.clone(),
    };
    // Verify signature — drop silently if invalid
    if role::verify_signature(&role, owner_vk_bytes).is_err() {
        return Ok(());
    }
    // INSERT OR IGNORE — don't overwrite an existing valid role
    db.conn().execute(
        "INSERT OR IGNORE INTO role (id,project_id,env_id,peer_id,level,granted_at,signature) VALUES (?1,?2,?3,?4,?5,?6,?7)",
        rusqlite::params![
            &role.id, &role.project_id, &role.env_id, &role.peer_id,
            role.level.as_str(), role.granted_at, &role.signature
        ],
    )?;
    Ok(())
}

/// Spawn a background task that listens for iroh-docs remote events and applies them to the DB.
/// The task runs until the node shuts down or the doc stream ends.
pub fn subscribe_and_apply(
    db_path: PathBuf,
    db_password: String,
    node: Arc<SyncNode>,
    doc_id: String,
    owner_pub_key: [u8; 32],
    our_identity: Identity,
    db_key: [u8; 32],
) -> JoinHandle<()> {
    tokio::spawn(async move {
        let client = node.client();
        let ns: iroh_docs::NamespaceId = match doc_id.parse() {
            Ok(n) => n,
            Err(_) => return,
        };
        let doc = match client.docs().open(ns).await {
            Ok(Some(d)) => d,
            _ => return,
        };
        let mut events = match doc.subscribe().await {
            Ok(s) => s,
            Err(_) => return,
        };
        while let Some(event) = events.next().await {
            let entry = match event {
                Ok(iroh::client::docs::LiveEvent::InsertRemote { entry, .. }) => entry,
                _ => continue,
            };
            let entry_key = String::from_utf8_lossy(entry.key()).to_string();
            let content = match doc.read_to_bytes(&entry).await {
                Ok(c) => c.to_vec(),
                Err(_) => continue,
            };
            let db_path2 = db_path.clone();
            let db_password2 = db_password.clone();
            let our_id = our_identity.clone();
            let owner_pk = owner_pub_key;
            let dk = db_key;
            tokio::task::spawn_blocking(move || {
                let db = match Db::open(&db_path2, &db_password2) {
                    Ok(d) => d,
                    Err(_) => return,
                };
                let _ = apply_entry(&db, &entry_key, &content, &owner_pk, &our_id, &dk);
            })
            .await
            .ok();
        }
    })
}

fn apply_entry(
    db: &Db,
    key: &str,
    content: &[u8],
    owner_pub_key: &[u8; 32],
    our_identity: &Identity,
    db_key: &[u8; 32],
) {
    if key == "project/meta" {
        if let Ok(meta) = serde_json::from_slice::<SyncProjectMeta>(content) {
            let _ = apply_project_meta(db, &meta);
        }
    } else if key.starts_with("env/") && key.ends_with("/meta") {
        if let Ok(meta) = serde_json::from_slice::<SyncEnvMeta>(content) {
            let _ = apply_env_meta(db, &meta);
        }
    } else if key.starts_with("secret/") {
        if let Ok(s) = serde_json::from_slice::<SyncSecret>(content) {
            let _ = apply_secret(db, &s);
        }
    } else if key.starts_with("role/") {
        if let Ok(r) = serde_json::from_slice::<SyncRole>(content) {
            let _ = apply_role_entry(db, &r, owner_pub_key);
        }
    } else if key.starts_with("peer_key/") {
        // Only process if this entry is for us
        let our_pub = our_identity.x25519_public();
        let our_peer_id = hex::encode(our_pub.as_bytes());
        if key == format!("peer_key/{our_peer_id}") {
            let _ = apply_peer_key_for_us(db, key, content, our_identity, db_key);
        }
    }
}

fn apply_project_meta(db: &Db, meta: &SyncProjectMeta) -> yasecret_core::Result<()> {
    db.conn().execute(
        "INSERT OR IGNORE INTO project (id,name,description,created_at,owner_id) VALUES (?1,?2,?3,?4,?5)",
        rusqlite::params![&meta.id, &meta.name, &meta.description, meta.created_at, &meta.owner_id],
    )?;
    Ok(())
}

fn apply_env_meta(db: &Db, meta: &SyncEnvMeta) -> yasecret_core::Result<()> {
    db.conn().execute(
        "INSERT OR IGNORE INTO environment (id,project_id,name,created_at) VALUES (?1,?2,?3,?4)",
        rusqlite::params![&meta.id, &meta.project_id, &meta.name, meta.created_at],
    )?;
    Ok(())
}

fn apply_secret(db: &Db, s: &SyncSecret) -> yasecret_core::Result<()> {
    // Archive existing value as a version if the secret already exists
    let existing: rusqlite::Result<(Vec<u8>, Vec<u8>, String, i64)> = db.conn().query_row(
        "SELECT encrypted_value, nonce, created_by, updated_at FROM secret WHERE env_id=(SELECT env_id FROM secret WHERE id=?1) AND key=?2",
        rusqlite::params![&s.id, &s.key],
        |r| Ok((r.get(0)?, r.get(1)?, r.get(2)?, r.get(3)?)),
    );
    if let Ok((old_enc, old_nonce, old_by, old_at)) = existing {
        let version_id = yasecret_core::models::new_id();
        let _ = db.conn().execute(
            "INSERT INTO secret_version (id,secret_id,encrypted_value,nonce,changed_by,changed_at,note) VALUES (?1,?2,?3,?4,?5,?6,NULL)",
            rusqlite::params![&version_id, &s.id, &old_enc, &old_nonce, &old_by, old_at],
        );
    }
    // Upsert the incoming secret
    db.conn().execute(
        "INSERT OR REPLACE INTO secret (id,env_id,key,encrypted_value,nonce,created_at,updated_at,created_by,expires_at) VALUES (?1,(SELECT env_id FROM secret WHERE id=?1),?3,?4,?5,?6,?7,?8,?9)",
        rusqlite::params![
            &s.id, &s.key,
            &s.encrypted_value, &s.nonce,
            s.created_at, s.updated_at, &s.created_by, s.expires_at
        ],
    )?;
    Ok(())
}

fn apply_peer_key_for_us(
    db: &Db,
    _key: &str,
    content: &[u8],
    our_identity: &Identity,
    _db_key: &[u8; 32],
) {
    let our_pub = our_identity.x25519_public();
    let our_peer_id = hex::encode(our_pub.as_bytes());
    // content is the raw blob from encrypt_for_peer — store as-is in peer_project_key
    // (project_id unknown here; we'd need it from project/meta — simplification: store with placeholder
    //  and fix up in the GUI/CLI layer after join completes)
    // For now: the CLI join command explicitly calls peer_key::load_my_peer_key after sync settles.
    // No DB write here — the blob is stored at push time by the OWNER via peer_key::store_peer_key.
    let _ = our_peer_id; // used above for matching
}

// ── Internal write helper ─────────────────────────────────────────────────────

async fn write_entry(
    node: &SyncNode,
    doc_id: &str,
    key: &[u8],
    value: Vec<u8>,
    author: &iroh::client::authors::AuthorId,
) -> Result<()> {
    let client = node.client();
    let ns: iroh_docs::NamespaceId = doc_id
        .parse()
        .map_err(|_| crate::SyncError::NoDoc(doc_id.to_string()))?;
    let doc = client
        .docs()
        .open(ns)
        .await
        .map_err(anyhow::Error::from)?
        .ok_or_else(|| crate::SyncError::NoDoc(doc_id.to_string()))?;
    doc.set_bytes(*author, key.to_vec(), value)
        .await
        .map_err(anyhow::Error::from)?;
    Ok(())
}
```

```rust
use clap::Args;
use std::time::Duration;
use yasecret_core::{environment, identity, models::Identity, project, project_key, secret};
use yasecret_sync::{
    applier::{push_env_meta, push_peer_key, push_project_meta, push_secret},
    doc_manager,
    node::SyncNode,
    peer_key::store_peer_key,
    types::{SyncEnvMeta, SyncProjectMeta, SyncSecret},
};

#[derive(Args)]
pub struct ShareArgs {
    #[arg(short, long)]
    pub project: String,
    /// Invitee's X25519 public key as 64-char hex (from `yasecret peers self` on their machine)
    #[arg(long)]
    pub peer_key: String,
    #[arg(long, hide = true)]
    pub db: Option<String>,
    #[arg(long, hide = true)]
    pub password: Option<String>,
}

pub async fn run(args: ShareArgs) -> yasecret_core::Result<()> {
    let path = crate::unlock::db_path(args.db.as_deref());
    let session = crate::unlock::unlock(&path, args.password.as_deref())?;

    let projects = project::list(&session.db)?;
    let proj = projects
        .iter()
        .find(|p| p.name == args.project)
        .ok_or_else(|| yasecret_core::YasecretError::NotFound(format!("project '{}'", args.project)))?;

    let proj_key = project_key::load(&session.db, &proj.id, &session.db_key)?;

    // Parse peer X25519 public key from hex
    let peer_pub_bytes: [u8; 32] = hex::decode(&args.peer_key)
        .map_err(|_| yasecret_core::YasecretError::EnvParse("invalid peer-key hex".into()))?
        .try_into()
        .map_err(|_| yasecret_core::YasecretError::EnvParse("peer-key must be 32 bytes (64 hex chars)".into()))?;
    let peer_id = args.peer_key.to_lowercase();

    // Encrypt project key for peer
    store_peer_key(&session.db, &proj.id, &peer_id, &peer_pub_bytes, &proj_key)
        .map_err(|e| yasecret_core::YasecretError::EnvParse(e.to_string()))?;

    // Start iroh node
    let data_dir = path.parent().unwrap().to_path_buf();
    let node = SyncNode::start(&data_dir, &[0u8; 32])
        .await
        .map_err(|e| yasecret_core::YasecretError::EnvParse(e.to_string()))?;

    // Create or get the iroh doc
    let ticket = doc_manager::create_project_doc(&session.db, &node, &proj.id)
        .await
        .map_err(|e| yasecret_core::YasecretError::EnvParse(e.to_string()))?;
    let doc_id = doc_manager::get_doc_id(&session.db, &proj.id)
        .map_err(|e| yasecret_core::YasecretError::EnvParse(e.to_string()))?;

    // Create an iroh author for our writes
    let author = node.client().authors().create().await
        .map_err(|e| yasecret_core::YasecretError::EnvParse(e.to_string()))?;

    // Push project meta
    let owner_id = identity::load(&session.db)?;
    let meta = SyncProjectMeta {
        id: proj.id.clone(),
        name: proj.name.clone(),
        description: proj.description.clone(),
        owner_id: proj.owner_id.clone(),
        owner_pub_key: hex::encode(owner_id.x25519_public().as_bytes()),
        created_at: proj.created_at,
    };
    push_project_meta(&node, &doc_id, &meta, &author)
        .await.map_err(|e| yasecret_core::YasecretError::EnvParse(e.to_string()))?;

    // Push environments + secrets
    let envs = environment::list(&session.db, &proj.id)?;
    for env in &envs {
        let env_meta = SyncEnvMeta {
            id: env.id.clone(),
            project_id: env.project_id.clone(),
            name: env.name.clone(),
            created_at: env.created_at,
        };
        push_env_meta(&node, &doc_id, &env_meta, &author)
            .await.map_err(|e| yasecret_core::YasecretError::EnvParse(e.to_string()))?;

        let secrets = secret::list(&session.db, &env.id)?;
        for s in &secrets {
            let sync_s = SyncSecret {
                id: s.id.clone(),
                key: s.key.clone(),
                encrypted_value: s.encrypted_value.clone(),
                nonce: s.nonce.clone(),
                created_at: s.created_at,
                updated_at: s.updated_at,
                created_by: s.created_by.clone(),
                expires_at: s.expires_at,
            };
            push_secret(&node, &doc_id, &env.id, &sync_s, &author)
                .await.map_err(|e| yasecret_core::YasecretError::EnvParse(e.to_string()))?;
        }
    }

    // Push encrypted project key for invitee
    let blob: Vec<u8> = session.db.conn()
        .query_row(
            "SELECT encrypted_key FROM peer_project_key WHERE project_id=?1 AND peer_id=?2",
            rusqlite::params![&proj.id, &peer_id],
            |r| r.get(0),
        )
        .map_err(|_| yasecret_core::YasecretError::NotFound("peer_project_key".into()))?;
    push_peer_key(&node, &doc_id, &peer_id, &blob, &author)
        .await.map_err(|e| yasecret_core::YasecretError::EnvParse(e.to_string()))?;

    // Small delay so iroh can propagate; then print ticket
    tokio::time::sleep(Duration::from_millis(300)).await;
    println!("{ticket}");

    node.stop().await;
    Ok(())
}
```

```rust
use clap::Args;
use std::time::Duration;
use yasecret_sync::{doc_manager, node::SyncNode};

#[derive(Args)]
pub struct JoinArgs {
    /// DocTicket string from `yasecret share`
    #[arg(short, long)]
    pub ticket: String,
    /// Local project name to associate the joined doc with
    #[arg(short, long)]
    pub project: String,
    #[arg(long, hide = true)]
    pub db: Option<String>,
    #[arg(long, hide = true)]
    pub password: Option<String>,
}

pub async fn run(args: JoinArgs) -> yasecret_core::Result<()> {
    let path = crate::unlock::db_path(args.db.as_deref());
    let session = crate::unlock::unlock(&path, args.password.as_deref())?;

    let projects = yasecret_core::project::list(&session.db)?;
    let proj = projects
        .iter()
        .find(|p| p.name == args.project)
        .ok_or_else(|| yasecret_core::YasecretError::NotFound(format!("project '{}'", args.project)))?;

    let data_dir = path.parent().unwrap().to_path_buf();
    let node = SyncNode::start(&data_dir, &[0u8; 32])
        .await
        .map_err(|e| yasecret_core::YasecretError::EnvParse(e.to_string()))?;

    let doc_id = doc_manager::join_project_doc(&session.db, &node, &args.ticket, &proj.id)
        .await
        .map_err(|e| yasecret_core::YasecretError::EnvParse(e.to_string()))?;

    // Wait for initial sync
    tokio::time::sleep(Duration::from_secs(2)).await;
```
